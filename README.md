# 小分表处理

## 目的
处理阅卷系统上直接下载的小分表，使之成为适合打印的形式。适用于高三年级物理科、凡高阅卷系统上直接下载的小分表。

## 用法

### 单文件处理
选择要处理的文件，然后输入考试名称（可选）和班级（可选），点击“处理并保存”按钮，在弹出的保存窗口中选择好保存位置，即可自动处理小分表并保存。默认勾选“处理完成后打开保存位置”，可在处理完成后直接弹出处理后文件的保存位置窗口。

文件将被处理成适合打印的形式，去掉冗余信息，调整好列宽，将单题0分的单元格标红，将扣卷面分的单元格标红，并自动汇总每题0分的学生与扣卷面分的学生。

如未输入考试名称和班级，则表格的首行留空，供手动填写标题；如已填写考试名称或班级，则自动生成小分表标题（形如“高三年级{{班级}}班{{考试名称}}考试物理成绩单”）。

### 多文件处理
选择输入和输出文件夹，然后输入考试名称（可选）和班级（可选），点击“处理”按钮，即可自动从输入文件夹中读取小分表，然后处理小分表并保存到输出文件夹。默认勾选“处理完成后打开输出文件夹”，可在处理完成后直接弹出输出文件夹窗口。

其余用法与单文件处理相同。
